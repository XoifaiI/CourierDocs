## Running it yourself

You need [Rojo](https://rojo.space), Git, the GitHub CLI and a Courier compiler built with `cargo build --release` in `compiler`.

<Steps>
<Step>

### Fetch the libraries

From `bench`, run `./fetch.sh`. It downloads every library at the version above into `bench/vendor` and compiles the bench schemas for the libraries that need a compiler.

</Step>
<Step>

### Serve the bench

Run `rojo serve bench/bench.project.json`, open an empty place in Studio, and connect.

</Step>
<Step>

### Pick a run

In `bench/Config.luau`, set `Run` to `"Throughput"` for these results. `Libraries` and `Tests` take lists of names if you only want some of them.

</Step>
<Step>

### Press Play

The results print to the output as tables when the run finishes.

</Step>
</Steps>

`Run = "Attack"` runs the other half of the bench.
